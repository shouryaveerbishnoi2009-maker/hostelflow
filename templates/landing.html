DATABASE-FIRST PHILOSOPHY

"Capture Once, Compute the Rest in SQL"

Rather than hiding complex queue computations and duration averages in slow Python application loops, HostelFlow executes everything inside PostgreSQL.

⚡ trg_fn_calculate_mess_exit(): Auto-computes exit time before insert by joining today's menu prep speed + eating buffer.
⚡ trg_fn_calculate_laundry_eta(): Snapshots active queue count on bag drop-off and projects pickup datetime.
⚡ v_live_mess_crowd: Computes active diners currently inside without needing manual exit scans.
schema.sql — trg_fn_calculate_mess_exit() 
-- Automated Exit Time Computation
NEW.mess_exit_time := NEW.mess_entry_time + 
  ((v_prep_time + v_avg_eating + v_buffer) 
   * INTERVAL '1 minute');

-- Real-Time Active Diners View
CREATE VIEW v_live_mess_crowd AS
SELECT h.hostel_id, h.hostel_name, COUNT(mv.visit_id)
FROM HOSTEL h
LEFT JOIN MESS_VISIT mv 
  ON NOW() BETWEEN mv.mess_entry_time 
               AND mv.mess_exit_time
GROUP BY h.hostel_id, h.hostel_name;
